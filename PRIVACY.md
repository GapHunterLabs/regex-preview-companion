# Privacy Policy — Regex Preview Companion

**Effective date:** 2026-08-14

Regex Preview Companion is a Gap Hunter Labs plugin for IntelliJ
Platform IDEs. This policy is short because the plugin's design makes
it short: there is nothing to disclose beyond what's below.

## What this plugin collects

**Nothing.** Regex Preview Companion does not collect, store,
transmit, or sell any data — no source code, no file contents, no
usage analytics, no telemetry, no crash reports, no personally
identifiable information. The pattern and sample text you type into
the tool window exist only in that window's own memory for as long as
the IDE is open.

## Network access

**None.** Regex Preview Companion makes zero network calls during
normal operation. Matching runs entirely in-process, inside your IDE.
Nothing you type is ever sent anywhere.

## Third parties

None. Regex Preview Companion has no third-party SDKs, no analytics
libraries, no ad networks, no external dependencies that phone home.

## Changes to this policy

If this ever changes, this file will be updated and the change will be
noted in the plugin's `CHANGELOG.md`.
